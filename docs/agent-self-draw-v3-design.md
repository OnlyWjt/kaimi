## 1. 账怎么算（确认后按这个做）

一张已出的卡，账面仍然只有三种：**未结算、已结算、已作废**。

| 操作 | 卡密还能兑吗 | 还算代理欠款吗 | 算进历史提卡吗 |
|---|---|---|---|
| 不作处理（未使用） | 能 | 算 | 算 |
| **手动核销**（这次新加） | 不能 | **算**，直到你登记结算 | **算** |
| 登记结算 | 看原来的使用状态 | 不算了 | 算 |
| 作废（误提、退卡） | 不能 | 不算 | **不算** |

历史提卡 = 未结算 + 已结算，**不含作废**。手动核销的卡在结算前算在未结算里，结算后算在已结算里，两边都能在历史合计里看到。

正在出卡、结果未知的单还没入库，不进历史合计。

## 2. 手动核销

### 2.1 和作废的差别

- **作废**：这张卡不该算给代理。误提、没发出去、要退。作废后代理少一笔，对账文本写「作废 N 张未计入」。
- **手动核销**：这张卡已经由你手工充掉了，代理还是要付钱。只是这张卡密不能再拿去兑换，免得重复用。

未结算列表里，未使用的卡两个按钮都在，文案写清楚：

```text
[ 手动核销 ]   卡密作废，金额仍算这个代理的
[ 作废 ]       不计欠款（误提、退卡才用这个）
```

### 2.2 条件

同时满足才能手动核销：

1. 账本状态是「未结算」；
2. 卡密还没被系统兑换（本地是未使用）。

已兑换的不用再点，金额本来就在未结算里。已结算的要先撤销账单。已作废的不能再核销。

### 2.3 流程

```text
┌ 手动核销这张卡？ ─────────────────────────┐
│ ZC-E5C9…D5C · Plus · 美区 · ¥150.00         │
│ 核销后这张卡密不能再兑换。                    │
│ 金额仍算阿明的小店的未结，不会少一单。         │
│ 原因 * [ 已手动充值                  ]       │
│                          [取消] [核销]      │
└─────────────────────────────────────────────┘
```

- **退卡台**，和作废同一套：先删卡退款，404 视为已删，405 改为禁用。卡台失败则本地账不改。
- 本地把卡密改成已禁用，兑换页查不到可用卡。
- 账本行仍是「未结算」，记下原因、操作人、时间。
- 使用列显示「手动核销」，不再显示「未使用」。
- 可以照常勾进「登记结算」。结算之后这张卡跟普通已结算卡一样进归档。
- 写审计 `admin.draw.item.manual_use`。

### 2.4 代理那边看到什么

未结算列表里这张卡还在，金额还在，使用状态是「手动核销」。对账文本照常计入合计，不写进「作废未计入」。

代理不能自己点手动核销，也不能作废。

### 2.5 数据库

`agent_draw_items` 加三列，不新开状态值：

| 列 | 含义 |
|---|---|
| `manual_used_at` | 核销时间，空表示没核销过 |
| `manual_used_by` | 操作的管理员 |
| `manual_note` | 原因，必填 |

卡密状态复用现有的 `disabled`。展示时：账本行有 `manual_used_at` 就显示「手动核销」，不要显示成「已作废」。

## 3. 每个代理的历史提卡

### 3.1 后台代理列表

现在一行是「未结 ¥X / 上限 ¥Y」。改成两行：

```text
onlyWjt                         已开通
未结 ¥2,800.00 · 23 张
历史 ¥18,400.00 · 146 张
```

历史 = 该代理全部未结算 + 已结算的金额和张数。作废不进这个数。

点进代理后，详情顶上三格：

| 未结 | 已结算 | 历史提卡 |
|---|---|---|
| ¥2,800.00 · 23 张 | ¥15,600.00 · 123 张 | ¥18,400.00 · 146 张 |

历史 = 未结 + 已结算。三格用同一个汇总函数算，避免对不上。

### 3.2 代理自己的提卡页

进度条下面加一行小字：「累计提卡 ¥18,400.00 · 146 张（不含作废）」。不给代理看别的店，也不给看上游进价。

## 4. 结算归档（单独表格 + 分页）

未结算账本只放还没结的卡，用来勾选、结算、核销、作废。

已结算从这里拿出去，单独一个「结算归档」页。现在的「已结算」子页改成这个，不再跟未结列表挤在一起，也不再一次只吐最近 200 笔。

### 4.1 查询

```text
代理 [全部 ▾]  关键词 [账单号 / 流水号 / 备注]  收款方式 [全部 ▾]  状态 [全部 ▾]
时间 [起] [止]                                          [查询] [清空] [导出]
共 86 笔，第 1 / 5 页                         [上一页] [下一页]
```

- 每页 **20** 笔账单。
- 时间按结算时间，含起止当天（北京时间）。
- 状态：已结算 / 已撤销 / 全部。已撤销的留在归档里，灰色，方便对当时点错的单。
- 导出 CSV 用当前筛选，导出全部命中行，不受当前页限制。列和现在一样。

### 4.2 表格

```text
账单号    代理      结算时间     张数  金额        方式    流水号    状态    操作
DB…A1    阿明      09-30 21:00   23   ¥2,800.00  支付宝  2026…    已结算  [明细] [撤销]
```

点「明细」在这一行下面展开卡密（脱敏）、套餐、金额、使用状态（含「手动核销」）。明细卡不多，一笔账单一次拉完，不再套一层分页。

撤销规则不变：7 天内、要填原因、卡回到未结算。撤销后这张账单还在归档里，状态变成已撤销。

### 4.3 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/draw` | 代理列表带上 `lifetimeCents`、`lifetimeCount`、`settledCents`、`settledCount` |
| GET | `/api/admin/draw/bills?page=1&pageSize=20&…` | 归档分页。返回 `{ list, total, page, pageSize }` |
| GET | `/api/admin/draw/export?kind=bills&…` | 按同样的筛选导出，不分页 |

筛选参数沿用现在的：`billAgentId`、`q`、`method`、`billStatus`，再加 `from`、`to`（`YYYY-MM-DD`，北京时间）。

未结算列表也分页，每页 20 张。勾选和登记结算只针对当前页。合计金额仍用全部未结，不按当前页算。
